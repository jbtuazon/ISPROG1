RAG: Notes first, Groq fills the gaps
Answers are generated by Groq (running open models like GPT-OSS) using your lecture notes as the primary source. Set up your API key to get started. Double-check anything graded.

Connect your Groq API key

This app runs entirely in your browser. Your key is stored only in this browser's local storage and is sent directly from your browser to Groq's API — it never passes through any other server.

How to get a free Groq API key

  1. Go to console.groq.com/keys and sign in (or create a free account).
  2. Click Create API Key, give it any name, and confirm.
  3. Copy the key it generates (it will look like gsk_…) — Groq only shows it once.
  4. Paste it into the field below and click Save & Test.

API key & model

openai/gpt-oss-120b (default) is the most capable and still very fast. openai/gpt-oss-20b is lighter/faster. groq/compound can also search the live web on its own if you want answers to reach beyond the notes and Groq's training data.

Security note: Because this is a single standalone HTML file with no backend, your API key lives in this browser only (do not hardcode it into the file or share the file with your key saved in it). Don't publish this page publicly with your key attached — treat it like a personal, local study tool.
